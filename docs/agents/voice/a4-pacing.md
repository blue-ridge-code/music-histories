# A4 · Pacing

> Component of the [language persona system](../language.md) — the speed of the
> story or argument, controlled by action, description, and breath. Kickoff fills
> "Project setting" when voice matters; blank = template defaults.

## What it is

Pacing is how fast the material moves for the reader. The research sources cover it
thinly (short sentences accelerate; features tolerate slower builds than news), so
most levers below are standard craft — flagged in
[research-notes.md](research-notes.md).

## Levers

- Sentence tempo: short accelerates, long decelerates (builds on A3).
- Ratio of action vs description vs exposition; scene vs summary.
- Detail density — more detail slows time down.
- Structural breath: section length, white space, headings, pauses.
- Genre tempo: a feature piece tolerates a slow build; a status report does not.

## Kickoff questions

- Does this project have narrative pacing at all (fiction, long features), or is
  "pacing" just document length and section sizing (docs, reports)?
- Where should the reader speed up and slow down?
- What stalls are acceptable — where may the writing dwell?

## Default (minimal kickoff)

Steady, moderate pacing matched to document type: concise and direct for docs/reports, no
narrative dwell. Minimal kickoff writes this default into "Project setting" as-is; the full
A1–B3 workshop is what refines it later, and is where narrative-heavy projects set real
scene/summary and detail-density choices.
