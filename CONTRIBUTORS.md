# Music Histories contributors

The collective attribution for original project contributions is
**Music Histories contributors**.

Git commit history records code and documentation authorship. Asset and source
records retain supplied individual credits. Contributors may add the name or
public handle they want credited, along with their contribution; do not publish
someone else's private contact details or infer authorship from a source title.

No individual contributor list has yet been curated. This does not replace or
remove existing copyright notices, asset credits, or attribution requirements.
